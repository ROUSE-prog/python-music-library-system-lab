# Python Music Library System Lab

A Python project demonstrating class attributes and class methods through a music library system.

## Features

- Create Song objects
- Track total song count
- Store unique genres
- Store unique artists
- Count songs by genre
- Count songs by artist

## Technologies

- Python 3
- Pytest

## Running Tests

```bash
pytest
```

## Example

```python
song1 = Song("Halo", "Beyonce", "Pop")
song2 = Song("99 Problems", "Jay Z", "Rap")
```
